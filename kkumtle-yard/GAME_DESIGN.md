# 꿈틀이의 앞마당 — 게임 설계 & 진행 기록

## 형식 (배포를 쉽게 하기 위한 결정)
- HTML5 Canvas + 순수 JavaScript, **파일 1개(index.html)**. 설치/빌드 없음, 이미지 파일 없음(그림은 코드로, 소리는 Web Audio로 합성).
- 그대로 올릴 수 있는 곳: Claude 아티팩트(현재), Vercel/Netlify/GitHub Pages, itch.io, CrazyGames·Poki(웹게임 포털).
- 나중에 앱스토어: 같은 파일을 Capacitor로 감싸서 Android/iOS 앱으로 변환 가능.
- 원본: game.html(본문) → build.sh가 dist/index.html(완전한 웹페이지)로 감쌈.

## 현재 구현(v1.2 — 버터 날갯짓 + 영어판)
- 이동: 터치 누른 채 방향 / 마우스 / 방향키·WASD. 넓은 마당(2400×1600) + 카메라 추적 + 미니맵.
- 영양분 5종: 낙엽🍂 커피찌꺼기☕ 달걀껍질🥚 바나나껍질🍌 당근꼭지🥕 → 몸 길어짐 + 흙 비옥도↑ + 콤보(최대 x5).
- 흙 비옥도: 마당을 50px 칸으로 나눠 0~1 저장. 머리가 지나가면 갈리고, 지렁이 똥(분변토)도 흙을 살림. 메마른 황토색 → 짙은 흙 → 초록, 풀이 자라고 꽃이 핌.
- 과일 식물 9곳(사과·복숭아·토마토·딸기·포도·수박): 주변 흙이 좋아질수록 과일이 열림.
- 퀘스트 3개 동시: 먹기 / 거리 / 몸길이 / 특정 밭 갈기 / 콤보 / 두더지 도망 / 두더지 싸대기. 완료 시 점수+흙 폭발+아이템. 3개마다 레벨업(하트 회복, 두더지 강화).
- 상장 5단계(비옥도 15/30/45/60/75%): 새싹 정원사상 → 꽃밭 지킴이상 → 주렁주렁 농부상 → 황금 과수원상 → 전설의 지렁이 대상.
- 두더지: 땅 흔들림 경고 2.3초 → 12초+ 추격(관성 있어 급회전으로 따돌리기 가능). 머리 물리면 하트-1, 꼬리 물리면 4마디 잘림. 끝까지 버티면 +150.
- 아이템(최대 3개씩): ⚡스피드 업(4초 1.75배) / 🌀땅굴 숨기(3.5초 안 보임) / ⭐슈퍼 꿈틀이(8초 무적·망토·금빛, 두더지가 도망감 → 부딪히면 "짝!!" 싸대기 연출 + 히트스톱 + +500).
- 🐦 앵무새 버터(대표님 댁 실제 앵무새 사진을 배경 제거해 사용, 파일 안에 내장): 26~38초마다 꿈틀이 앞쪽에 빨간 착륙 표시(반경 85px~125px) + 카운트다운(3.3초→최소 2.2초). 착륙 순간 표시 안에 있으면 "콕콕!" → 점수 -(100+50×레벨), 몸 -3마디, 1.6초간 속도 절반, 버터가 신나서 콩콩 뛰며 따라옴. 피하면 +80점 & "삐잉…?". 땅굴 숨기 중이면 안전, 슈퍼 꿈틀이면 버터가 깜짝 놀라 도망. 레벨 2 이하에선 두더지와 겹치지 않음. 퀘스트 "버터 착륙 지점 피하기 x2" 추가.
- 버터 날갯짓: 사진은 날개 접은 모습이라 코드로 그린 왕관앵무 날개(회색 칼깃 7장 + 흰 덮깃 무늬)를 어깨에 붙여 퍼덕임. 날아올 땐 빠르게, 착륙 직전엔 크게 천천히, 신났을 땐 제자리에서 퍼덕. "퍼덕퍼덕" 글씨·깃털·날갯짓 소리.
- 날씨: 가끔 비 → 영양분 쏟아짐, 속도 +15%.
- 최고점수 저장(브라우저), 음소거, 일시정지, 탭 이동 시 자동 일시정지.

## 코드 구조 (v1.5부터)
- 원본: `src/` (한국어 기준). `src/index.html`(화면·스타일) + `src/js/` 파일 8개(00-core, 10-land, 20-enemies, 30-game, 40-draw, 50-world, 60-burrow, 90-main). `src/index.html`을 더블클릭하면 빌드 없이 바로 실행(개발용).
- 빌드: `node build.mjs` → `public/index.html`(영어, 기본) + `public/ko.html`(한국어). 파일 하나에 코드·그림 모두 포함. Vercel이 배포 때 자동 실행(vercel.json).
- 번역: 새 문구는 코드에 `L('한국어', 'English')`로 적기. 예전 문구는 `src/i18n-en.json` 번역표. 빌드 때 빠진 번역이 있으면 경고.
- 기본 언어: 영어(`/`), 한국어는 `/ko`.

## 학교 모드: 버터 교수님 퀴즈 & 하우스 대항전 (v2.0)
- 처음 시작할 때 프로필: 닉네임(실명 금지 안내)·학년(Year 7, Year 8, Shell, Remove, Hundred, Lower/Upper Sixth)·반(Y7–8: 1–3반) 또는 하우스(Shell 이상, 4개). 시작 화면 👤 줄에서 언제든 바꿈. 이름·이메일·사진은 받지 않음.
- 문제 은행(js/72-quiz-bank.js): 영어 160문제 = 4수준(prep Y7–8 / shell Y9 / igcse Y10–11 / sixth) × 5과목(생물·화학·물리·지리·수학) × 8문제. 첫 번째 보기가 정답, 게임 안에서 섞음. 최근 120문제는 다시 안 나오게 기억. ✏️ 패트릭·헨리가 정답 검수 필요.
- 퀴즈가 나오는 순간(진행을 막지 않음, 건너뛰기 가능, 틀려도 벌칙 없음): 레벨업(생물/물리/수학 돌아가며), 다른 나라 도착(지리), 구조 성공(생물), 두더지 굴 완주(화학), 일시정지 화면의 "📚 퀴즈 한 문제". 정답 +500점.
- 하우스 점수(이번 주, 월요일 초기화): 퀴즈 정답 1점(하루 20점까지) + 게임 끝날 때 점수 3,000점당 1점 + 구조한 나라 2점씩 + 엔딩 5점(하루 15점까지). → 게임 실력과 공부 둘 다 의미 있게, 하루 한도로 밤샘 몰아치기 방지.
- 🏰 대항전 화면: 하우스 막대그래프 / Year 7·8 반 그래프 / 개인 / 내 기여(오늘 한도, 정답률).
- 온라인: 73-school.js의 SCHOOL.api(url, key)를 채우면 Supabase RPC(add_points, board_houses, board_classes, board_players)로 모든 학생 점수가 모임. 비어 있으면 이 기기 기록만 보임. Claude 미리보기 페이지는 외부 접속이 막혀 있어 Vercel 배포본에서만 작동.
- 하우스: 시니어 10개(데이 Bickerton·Butler·Morley·Sheppard·Thompson·Wallace + 보딩 Honan·Munawir Hill·Steel·Wills, 학교 홈페이지 기준). 색(패트릭 확인): Butler·Sheppard 초록, Morley·Bickerton 주황, Wallace·Thompson 핑크, Steel 빨강, Honan 초록+노랑, Munawir Hill 노랑+빨강, Wills 하늘+빨강(두 색은 줄무늬). Year 7–8은 반(1–3) 대항. 학교 이름·로고는 넣지 않음.

## 휴대폰 조이스틱 (v2.1)
- 휴대폰(터치)에서는 화면 아무 데나 엄지를 대면 그 자리에 조이스틱이 생기고, 민 방향으로 꿈틀이가 감(손가락이 지렁이를 가리지 않음). 왼쪽 아래에 흐린 조이스틱 표시. 아이템 버튼은 오른쪽 아래 → 양손 조작.
- 버터 비행도 같은 조이스틱 + 오른쪽 발사 버튼. 두더지 굴은 그대로 탭 점프. PC는 마우스·방향키 그대로.

## 가로 화면 & 두 손가락 (v2.2)
- 휴대폰 가로(높이 500px 이하)에서는 정보창·퀘스트창·작은 지도·아이템 버튼을 작게. 퀘스트 제목을 누르면 접고 펼 수 있음(기억됨).
- 아이템 버튼은 누르는 순간 작동(pointerdown) → 조이스틱을 잡은 채로 다른 손가락으로 스피드·땅굴·슈퍼 사용 가능.

## 엔딩 & 명예의 전당 & 선명도 (v1.8)
- 선명도: 캔버스 이모지가 바로 전에 쓴 반투명 그림자 색을 따라 흐려지던 문제 수정(이모지는 항상 진한 색 + 살짝 그림자). 영양분·아이템 크기도 키움.
- 엔딩: 5개 나라를 모두 구하면 구조 증서에 "🌍 엔딩 보기" → 초록 지구가 돌고 불꽃놀이 + 꿈틀이·버터·망고·세계 동물 퍼레이드 + 엔딩 크레딧(기록, 출연, 만든 사람: 아빠와 아들, 지렁이 이야기) 30초(건너뛰기 가능) → 엔딩 보너스 +10,000 → 이름 등록 → '계속 놀기(끝없는 모드)' 가능. 엔딩 전용 축하 행진곡.
- 명예의 전당: 기기(브라우저)마다 상위 10개 저장. 게임 오버·엔딩 때 10위 안이면 이름 입력(12자) → 순위 표시(내 기록 강조, 엔딩 본 기록은 🌍). 시작 화면 '🏆 순위' 버튼. 이름 입력 중엔 게임 단축키 무시.
- 온라인(전 세계) 순위표는 아직 아님: 하려면 별도 DB(예: Supabase 새 프로젝트) 필요.

## 나라별 동물 · 메뚜기 떼 · 천둥번개 (v1.7)
- 다른 나라 마당에서는 망고가 집에서 기다리고, 그 나라 동물이 등장:
  - 호주: 캥거루(만지면 주머니에 5초 태워 깡총깡총 — 메마른 쪽으로 뛰며 착지마다 흙 갈기), 코알라 2마리(나무 위에서 자다 유칼립투스 잎 = 영양분 떨어뜨림)
  - 몽골: 쌍봉낙타 2마리(낙타 똥 거름 💩: 흙 효과 큼), 말 떼(30~45초마다 꿈틀이 근처 가로줄에 빨간 경고 2.3초 → 말 4마리 질주. 맞으면 뻥! 2마디·80점·잠깐 멈춤, 지나간 줄은 흙이 부드러워짐)
  - 마다가스카르: 여우원숭이 2마리(영양분을 주워 꿈틀이 옆에 선물), 카멜레온(반투명하게 숨어 있다 혀로 지네·도마뱀 사냥)
  - 니제르: 단봉낙타(거름), 기린(나무 잎을 뜯다 떨어뜨림), 쇠똥구리(경단이 점점 커짐 — 꿈틀이가 건드리면 거름 폭탄 +150)
  - 칠레: 라마 2마리(앞에 있으면 침 퉤 → 1.4초 느려짐 + 얼굴에 침), 플라밍고(소금 호수, 장식)
- 메뚜기 떼(레벨 2부터, 80~110초마다, 비 올 땐 안 옴): 나무 3그루를 차례로 9초씩 갉아먹어 시들게 함(과일 줄고 흙도 약간 나빠짐). 시든 나무 주변 130px에 꿈틀이가 머물면 회복(완전 회복 +300). 망고·병아리가 메뚜기를 먹고, 슈퍼 꿈틀이는 떼를 흩어 버림(+300), 비가 오면 도망감. 화면 밖이면 🦗·🥀 화살표.
- 천둥번개(비 올 때, 비 18초로 늘림): 2.2~3.8초마다 노란 원으로 번개 자리 예고(1.2초). 12%는 꿈틀이가 가는 방향에 짧은 예고(0.5초)·큰 원으로 치는 '피하기 어려운 번개'. 맞으면: 1초간 뼈가 보이며 번쩍번쩍 + 전기 줄기(움직일 수 없음) → 2.5초간 숯검댕이 + 뻗친 머리 + 연기. 1마디·50점 감점(목숨은 안 깎임). 슈퍼 꿈틀이는 오히려 3초 충전, 땅굴 숨기 중엔 안전. 망고도 맞으면 시커멓게 변하고 "꼬꼬댁!!", 지네·도마뱀은 사라짐. 번개 맞은 자리는 흙이 좋아짐(질소 — 첫 번개 때 설명 배너).

## 닭 망고 & 마당 생물 (v1.6)
- 망고(대표님 댁 닭 사진, 풀에 가려진 다리는 지우고 코드로 걷는 다리를 그림): 마당을 돌아다니다 눈앞(앞쪽 반원, 약 260px)에 있는 걸 쫌. 우선순위 지네·도마뱀 > 두더지 > 꿈틀이 > 영양분.
  - 이이제이: 두더지를 망고 앞으로 유인 → 망고가 두더지를 쪼아서 쫓아냄 (+300, 두더지 따돌림으로 인정, 굴 입구 생김). 첫 두더지 추격 때 힌트 배너.
  - 꿈틀이도 쪼임: -(80+20×레벨)점, 2마디, 잠깐 느려짐. 한 번 쪼면 7초 동안은 꿈틀이를 안 노림. 땅굴 숨기·슈퍼 꿈틀이면 안전.
  - 먹을 때마다 뚱뚱해짐(지네·도마뱀 +2, 두더지·영양분 +1). 6이 되면 "꼬꼬댁!" 하고 달걀을 낳음.
- 달걀: 꿈틀이가 건드리면 '달걀 껍질 칼슘' → 주변 흙 크게 좋아짐 + 200점 + 35% 확률 아이템. 그냥 두면 25초 뒤 병아리 부화(최대 3마리) → 병아리는 지네·도마뱀만 잡아먹는 도우미. 도마뱀이 달걀을 훔쳐 먹기도 함.
- 도마뱀(2마리): 영양분·달걀 도둑. 꿈틀이가 부딪히면 꼬리를 끊고 도망(꼬리 줍기 +100). 꼬리는 20초 뒤 다시 자람.
- 지네(1~2마리): 꿈틀이를 쫓아오는 사냥꾼. 물리면 3마디 잘림, 100점 감점, 독 때문에 1.8초 느려짐. 슈퍼 꿈틀이는 지네를 물리침.
- 잡아먹힌 생물은 15~22초 뒤 마당 가장자리에서 다시 나타남.

## 두더지 굴 개편 (v1.6)
- 버그 수정: 두 번째 굴부터 도착해도 보상 창이 안 뜨고 멈추던 문제(비행 도착도 같은 문제) 수정.
- 더 어렵게: 속도 360(레벨마다 +15, 최대 440), 구간 수 14+레벨, 체크포인트 4구간마다, 레벨 1부터 난이도 3까지.
- 동굴 천장이 구간마다 넓음(60)·보통(120)·낮음(190)·좁음(250)으로 바뀜(비탈로 이어짐). 좁은 곳엔 천장 가시가 나와서 점프하면 안 되는 구간도 있음.
- 새 장애물: 떨어지는 종유석(가까이 가면 흔들리다 떨어져 바닥에 꽂힘), 천장 가시, 구덩이 위 기둥 건너뛰기, 박자 맞춰 연속 점프, 버섯 연속 점프, 중력 반전 + 바닥 가시 조합.
- 벽 속 생물: 기어가는 다른 지렁이, 개미 줄, 딱정벌레, 실 타고 내려오는 거미, 반짝이는 빛벌레.

## 남은 꿈틀이(목숨) & 두더지 굴 (v1.5)
- 목숨 3개(꿈틀이 아이콘, 화면 왼쪽 위). 잃는 경우: 마당에서 두더지에게 머리를 잡힘 / 비행 중 버터 기운(💛 3칸)이 다 떨어져 추락 / 두더지 굴에서 장애물에 부딪힘. 0이 되면 게임 끝. 마당 레벨업 때 1개 회복(최대 3).
- 두더지 굴: 두더지를 끝까지 따돌리면 그 자리에 굴 입구가 15초 동안 생김 → 들어가면 지하 러너.
  - 자동으로 달림, 탭/스페이스/↑ 점프(꾹 누르면 더 높이, 누르고 있으면 연속 점프). 140bpm 박자 간격으로 장애물 배치, 같은 레벨은 매번 같은 지형.
  - 장애물: 뾰족 돌, 흙 블록(위에 올라탈 수 있음, 옆에 부딪히면 실패), 지하수 웅덩이, 굴러오는 바위, 나무뿌리(점프하면 걸림), 점프 버섯, 중력 반전 포털(천장 달리기). 3묶음마다 체크포인트.
  - 💎(+50)·🦴(+150) 수집, 끝에 두더지 비밀 창고: 아이템 3종 +1, 보너스 점수. 나오면 굴 주변 흙이 확 살아남.
  - 음악: 일렉트로 140bpm. 세로 화면이면 가운데 띠로 보여 줌(가로 권장).
- 다음 후보(③): 나라 이동 때 '지구 관통 터널' 보너스 선택지.

## 세계 구조 대작전 (v1.4)
- 버터 꼬리 쪼기: 착륙 순간 머리가 아니라 몸통/꼬리(5번째 마디부터)가 표시 안에 있으면 "꼬리 콕!" → 쪼인 곳부터 꼬리 끝까지 최대 5마디 잘림, 점수는 머리 쪼임의 절반, 0.6초 느려짐.
- 마당 레벨 3 → 지구본 화면 "📡 SOS!". 이후 HUD 🌍 버튼으로 언제든 열기.
- 지구본: 실제 육지 지도(144×72 점)를 회전하는 지구로 그림. SOS 나라 5곳: 호주 아웃백·몽골 고비·마다가스카르·니제르 사헬·칠레 아타카마. 거리(km)로 난이도 ★1~3. 선택하면 비행 경로 표시.
- 비행(가로 슈팅, 세로 화면이면 위로 나는 세로 슈팅으로 자동 회전): 드래그/방향키로 이동, 💩 발사 버튼/스페이스로 버터가 부리를 쩍 벌려 지렁이 똥 발사.
  - 적: 까마귀(물결), 급강하 까마귀, 큰 까마귀(깃털 발사), 번개 구름(예고 후 번개), 끝판왕 "까마귀 대장 까옥이"(깃털 부채·부하 소환·돌진, 체력 절반 이하 분노).
  - 간식: 귀리·해바라기씨·브로콜리·사과 조각 → 점수 + "버터 신남" 게이지. 가득 차면 버터 피버 7초(무적+무지개 연사+노래).
  - 파워업: 황금 기장(세 갈래 발사), 깃털 방패, 하트. 연속 격추 콤보 x5. 기러기 친구들(쏘면 -50).
  - 배경: 아침→노을 하늘, 바다(배·고래)→도착 나라 땅(나라별 동물/풍경 이모지).
- 도착 → 그 나라 마당: 흙 색·과일(예: 몽골 비타민나무·감자·밀, 마다가스카르 바나나·카카오·바닐라 대신 커피 등)·간판 인사말이 바뀜. 미션: 흙 40% → 구조 성공 증서 + 보너스, 다음 나라 선택. 구조한 나라 국기는 브라우저에 저장되어 시작 화면에 표시.
- 음악 추가: 지구본(신비로운 패드+종), 비행(8비트 칩튠 152bpm), 대장 까마귀(D단조 168bpm), 도착 팡파르.
- 새 문구는 코드 안에서 L('한국어', 'English')로 두 언어를 함께 적음 → 번역표에 따로 안 넣어도 됨.

## 배경음악 (v1.3) — Doors식 적응형 음악, 밝은 분위기
- 전부 코드로 작곡·합성(Web Audio). 음원 파일 없음, 저작권 걱정 없음. 박자 단위로 정확히 예약 재생(룩어헤드 스케줄러).
- 곡: 로비(라운지, F장조 100bpm) / 탐험(G장조 116bpm, I–V–vi–IV) / 위기(두더지 경고·버터 접근, 2마디마다 반음 상승) / 추격(A장조 160bpm 록) / 슈퍼 꿈틀이(C장조 136bpm 금관 팡파르, I–♭VI–♭VII–I) / 게임오버(한 번만).
- 전환: 위기·추격·슈퍼는 다음 박에서 바로, 나머지는 다음 마디에서. 추격·슈퍼 시작 때 심벌 한 방.
- 탐험곡은 흙 비옥도 12/30/45/60%마다 악기 층 추가(드럼→종소리→아르페지오→패드). 비 올 때 반짝이는 종소리.
- 땅굴 숨기·일시정지·상장 화면에선 벽장에 숨은 듯 먹먹하게(로우패스 650Hz).
- 🎵 버튼으로 음악만 끄기(소리 효과는 유지), 🔊는 전체 음소거.
